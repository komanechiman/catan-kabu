# カタン株 〜ランタン通りの大富豪〜

カタンのルール（サイコロ・数字チップ・盗賊）を株に置きかえた、家族で遊ぶスマホ用ボードゲームです。
2〜4人がそれぞれのスマホで同じ部屋に入って遊びます。10歳からOK。

- 遊ぶのにお金は一切かかりません（GitHub Pages ＋ Firebase 無料プラン）
- インストール不要。ブラウザで URL を開くだけ
- 本物のお金を賭ける機能はありません。「負けた人のおねがい」（皿洗いなど）を設定できます

公開URL：https://komanechiman.github.io/catan-kabu/

## あそびかた

1. 1人が「部屋を作る」→ 名前とキャラを選ぶ → 4文字の合言葉が出る
2. ほかの人は「合言葉で入る」から同じ合言葉を入力（リンクを LINE で送ってもOK）
3. ロビーでラウンド数と「負けた人のおねがい」を決めて「ゲームスタート」

### 1ラウンドの流れ

| 手順 | 内容 |
|---|---|
| 🎲 親がサイコロを2つ振る | 合計の数字の会社に**ニュース**が起きて、株が上がったり下がったりする。ほかの会社も少しだけ動く |
| 🏴‍☠️ 7が出たら盗賊 | 親が好きな会社に送りこむ。その株は −25% |
| 📰 ゾロ目は号外 | 町じゅうの株が +25% か −25% |
| 🛒 売り買いタイム | 全員同時に買ったり売ったり。全員が「おしまい」を押したら次のラウンド |

最後のラウンドが終わったとき、**お金＋持っている株の値段**が一番多い人の勝ち。みんな 1,000G からスタート。

### 5つの会社（カタンの資源に相当）

| 会社 | 出目 | ニュースが起きる確率 | 性格 |
|---|---|---|---|
| 🏮 ランタン工房 | 6・8 | 36回に10回 | 安定。小さくコツコツ。たまに配当 |
| 🧱 石畳ギルド | 5・9 | 36回に8回 | そこそこ動く |
| 🌿 薬草園カモミラ | 4・10 | 36回に6回 | 当たるとよく伸びる |
| 🐟 魚の塔商会 | 3・11 | 36回に4回 | 大波が来る |
| ⛏️ 竜の鉱山 | 2・12 | 36回に2回 | 一発逆転か、ドカンか |

ニュースは会社ごとのカードから引かれます。「巨大マグロが釣れた！ +30%」「ドラゴンが怒って坑道が崩れた −50%」のように、なぜ上がったか・下がったかが必ず分かります。

### 教育のねらい

- **ニュースで株が動く**：理由があって値段が変わる
- **安定な会社と荒れる会社がある**：6・8はよく当たるけど小さく、2・12はめったに当たらないけど大きい
- **1社に全部つっこむと痛い目にあう**：分散
- **下がったときに売ると損が決まる**：ガチホの勇気

タイトル画面の隅に「こどもNISAのはなし」（3ページ＋クイズ3問）もあります。

## 公開するまでの手順（最初の1回だけ）

### 1. Firebase（無料・カード不要）

1. https://console.firebase.google.com →「プロジェクトを追加」→ Google アナリティクスは**オフ**
2. 左上 ≡ →「構築」→「Realtime Database」→「データベースを作成」→ ロケーション **シンガポール** → **テストモード**
3. 「ルール」タブ → 中身を `database.rules.json` の内容に置き換えて「公開」（テストモードは30日で切れるので必須）
4. ≡ → ⚙ →「プロジェクトの設定」→「マイアプリ」→ `</>` → アプリを登録（Hosting はチェックしない）
5. 出てきた `firebaseConfig` を `js/firebase-config.js` に貼り付けて保存

> このキーは「ブラウザに配っても良い」種類です。データの保護は Firebase のルール側で行います。
> 無料プラン（Spark）のままで十分です。Blaze にアップグレードしないでください。

### 2. GitHub Pages

リポジトリの Settings → Pages → Source「Deploy from a branch」→ Branch **main** / **/(root)** → Save。
1〜2分で `https://＜ユーザー名＞.github.io/catan-kabu/` で開けます。スマホで「ホーム画面に追加」すると便利。

## 開発メモ

- ビルド不要の素の HTML / CSS / JavaScript（ES Modules）
- `js/engine.js`：ルール計算（純粋関数）。`js/app.js`：画面と Firebase 通信。`js/data.js`：会社・ニュースカード・キャラ・レッスン
- 部屋の状態は `rooms/{合言葉}` に1つの JSON として保存し、すべての操作をトランザクションで更新
- 対戦の記録は `history/{id}` に追記
- テスト：`node --test test/engine.test.mjs`
- ブラウザの動作確認：`node test/smoke.mjs`（Playwright が必要。Firebase をスタブに差し替えて2人分のページでゲームを通す）

### 設計の制約

- 認証なしのため、合言葉を知っている人は誰でも部屋に書き込めます（家族・友人で遊ぶ前提）
- Firebase 無料プランの範囲（同時接続100、転送量 10GB/月）で十分に遊べます

### ニュースカードを増やす・調整する

`js/data.js` の `COMPANIES[].cards` に `{ t: '見出し', p: 変化率% }` を足すだけ。`div: 5` を付けると「1株につき5G」の配当カードになります。
