# カタン株 〜ランタン通りの大富豪〜

カタンのルール（サイコロ・数字チップ・盗賊・交渉）を株式市場に置きかえた、家族で遊ぶスマホ用ボードゲームです。
2〜4人がそれぞれのスマホで同じ部屋に入って遊びます。信用取引・空売り・投資信託・つみたて・「こどもNISA」レッスン付き。

- 遊ぶのにお金は一切かかりません（GitHub Pages ＋ Firebase 無料プラン）
- インストール不要。ブラウザで URL を開くだけ
- 本物のお金を賭ける機能はありません。「負けた人のおねがい」（皿洗いなど）を設定できます

## 1. 公開するまでの手順（最初の1回だけ）

### 1-1. Firebase プロジェクトを作る（無料・クレジットカード不要）

1. https://console.firebase.google.com を開いて Google アカウントでログイン
2. 「プロジェクトを追加」→ 名前は `catan-kabu` など → Google アナリティクスは **オフ** → 作成
3. 左メニュー「構築」→「Realtime Database」→「データベースを作成」
   - ロケーション：**シンガポール（asia-southeast1）** を選ぶ（日本に近い）
   - セキュリティルール：「**テストモード**」で開始（あとで差し替える）
4. 作成されたら「ルール」タブを開いて、中身をこのリポジトリの `database.rules.json` の内容に**まるごと置き換えて**「公開」
   （テストモードのルールは30日で期限切れになるため、必ず置き換えてください）
5. 左上の歯車 →「プロジェクトの設定」→ 下の「マイアプリ」→ `</>`（ウェブ）をクリック
   - アプリのニックネーム：`catan-kabu`
   - 「Firebase Hosting も設定する」は **チェックしない**
   - 「アプリを登録」→ 表示される `const firebaseConfig = { ... }` の中身をコピー
6. このリポジトリの `js/firebase-config.js` を開いて、`YOUR_...` の部分を全部コピーした値に置き換える
   - GitHub のサイト上なら、ファイルを開いて鉛筆アイコン → 編集 → 「Commit changes」でOK
   - `databaseURL` が入っていることを確認（Realtime Database を先に作っていれば入っています）

> このキーは「ブラウザに配っても良い」種類のキーです。データの保護は Firebase のルール側で行います。
> 無料プラン（Spark）のままで十分です。「Blaze（従量制）」にアップグレードしないでください。

### 1-2. GitHub Pages で公開する

1. GitHub のリポジトリページ →「Settings」→ 左の「Pages」
2. 「Source」を **Deploy from a branch**、Branch を **main** / **/(root)** にして「Save」
3. 1〜2分待つと `https://＜ユーザー名＞.github.io/catan-kabu/` で開けるようになります

スマホで開いたら「ホーム画面に追加」しておくと、アプリみたいに起動できます。

## 2. あそびかた

1. 1人が「部屋を作る」→ 名前とキャラを選ぶ → 4文字の合言葉が出る
2. ほかの人は「合言葉で入る」から同じ合言葉を入力（リンクを LINE などで送ってもOK）
3. ロビーでラウンド数・制限時間・「負けた人のおねがい」などを決めて「ゲームスタート」

### 1ラウンドの流れ

| 手順 | 内容 |
|---|---|
| 🎲 親がサイコロを3つ振る | 2個の合計で「当たる会社」が決まり、その株が上がる（配当も）。3個目はイベントダイス（📈大暴騰 / 📉大暴落 / 🌊凪 / なし） |
| 🏴‍☠️ 7が出たら盗賊 | 親が盗賊を置く会社を選ぶ。その株は −20%、次の7まで上がらない。現金を5万Gより多く持っている人は超過分の10%を盗まれる |
| 🛒 取引タイム | 全員同時に売買・借入・空売り・つみたて設定・プレイヤー同士の交換 |
| ✅ 全員「おしまい」 | 次のラウンドへ。親は順番にまわる |

決めたラウンド数が終わったとき、**純資産**（現金＋持ち株−借金）が一番多い人の勝ちです。

### 銘柄（カタンの資源に相当）

| 銘柄 | 出目 | 当たる確率 | 当たると | 配当 | 性格 |
|---|---|---|---|---|---|
| 🏮 ランタン工房 | 6・8 | 10/36 | +8% | 3% | 安定・配当 |
| 🧱 石畳ギルド | 5・9 | 8/36 | +12% | 2% | バランス |
| 🌿 薬草園カモミラ | 4・10 | 6/36 | +18% | 1% | 成長 |
| 🐟 魚の塔商会 | 3・11 | 4/36 | +30% | なし | ハイリスク |
| ⛏️ 竜の鉱山 | 2・12 | 2/36 | +70% | なし | ギャンブル（平均では少し下がる） |

### 投資信託（NISA の勉強用）

| ファンド | 中身 | 信託報酬 | ねらい |
|---|---|---|---|
| 🧺 全部入りファンド | 5社の平均に連動 | 0.1%/R | インデックスファンド。「安く・広く・長く」 |
| 🔮 魔法使いのおまかせファンド | 平均 ± 魔法使いの腕（ランダム） | 1.5%/R | アクティブファンド。手数料が重い |
| 💸 毎月分配ファンド | 平均に連動、毎ラウンド4%を現金で配る | 1.2%/R | 分配金は元本の切り崩し（タコ足配当）を体験 |

🤖 **つみたてくん**：毎ラウンド同じ金額を全部入りファンドに積み立てるだけのボット。結果画面でみんなと比較されます。

### 上級ルール（警告つき）

- **信用取引**：純資産の2倍まで借りられる。毎ラウンド2%の金利
- **空売り**：純資産と同額まで。毎ラウンド1%の貸株料。株が上がると損失に上限なし
- **追証**：維持率（純資産÷ポジション）が25%を切ると全部強制決済
- **破産**：純資産がマイナスになると 10,000G からやり直し

## 3. 教育のねらい

- サイコロの確率（6・8は出やすく、2・12は出にくい）が、そのまま「リスクとリターン」の関係になっている
- 信用取引と空売りは「もうけも損も倍になる」ことを、追証と破産で体感する
- 投資信託3本の比較で「手数料の差」「分配金のワナ」を体感する
- つみたてくんに負けることで「ほったらかし積み立ての強さ」を知る
- ゲーム後の「こどもNISAレッスン」で、現実の商品選びのチェックリストとクイズ、最後に自分で選ぶ

こどもNISA の制度内容（2027年1月開始予定、0〜17歳、年60万円・上限600万円、対象は長期・積立・分散向けの投資信託）は 2026年10月時点の公表情報にもとづいています。細部は変わる可能性があるので、実際に口座を作るときは金融庁・証券会社の最新情報を確認してください。

## 4. 開発メモ

- ビルド不要の素の HTML / CSS / JavaScript（ES Modules）
- `js/engine.js`：ルール計算（純粋関数）。`js/app.js`：画面と Firebase 通信。`js/data.js`：銘柄・キャラ・用語・レッスン
- 部屋の状態は `rooms/{合言葉}` に1つの JSON として保存し、すべての操作をトランザクションで更新
- 対戦の記録は `history/{id}` に追記（追記のみ可能なルール）
- テスト：`node --test test/engine.test.mjs`
- ブラウザの動作確認：`node test/smoke.mjs`（Playwright が必要）

### 設計の制約

- 認証なしのため、合言葉を知っている人は誰でも部屋に書き込めます（家族・友人で遊ぶ前提）
- Firebase 無料プランの範囲（同時接続100、転送量 10GB/月）で十分に遊べます
